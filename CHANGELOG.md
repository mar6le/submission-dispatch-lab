# Історія випусків

## v1.2.0

API створює і знаходить подання, а повтор ключа повертає наявний номер. Лічильники й журнали HTTP винесено до окремого модуля.

Після коміту імітується передача підтвердження з номером доставки. Режим closed повертає 503 після збереження. /health та читання існуючих записів працюють.
